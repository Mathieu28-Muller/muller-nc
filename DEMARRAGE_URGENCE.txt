    git clone https://github.com/Mathieu28-Muller/muller-nc.git C:\formation

  ÉTAPE 2 — Installer les dépendances Node.js
    cd C:\formation && npm install
    cd C:\formation\certificat-conformite && npm install

  ÉTAPE 3 — Installer PostgreSQL 16
    Télécharger depuis https://www.postgresql.org/download/windows/
    Créer la base : psql -U postgres -c "CREATE DATABASE nc_muller;"
    Appliquer le schéma : psql -U postgres -d nc_muller -f schema_postgresql.sql
    Migrer les données : node migrate.js

  ÉTAPE 4 — Créer le fichier .env
    Copier depuis C:\Users\MULLER\Documents\SECRETS_DEPLOIEMENT_NC.txt
    (gabarit complet .env PC inclus dans ce fichier)

  ÉTAPE 5 — Installer PM2 et démarrer
    npm install -g pm2
    npm install -g pm2-windows-startup
    pm2-startup install
    cd C:\formation && pm2 start ecosystem.config.js && pm2 save

  ÉTAPE 6 — Installer Nginx
    Copier C:\tools\nginx-1.29.7\ depuis backup D:\
    Démarrer : C:\tools\nginx-1.29.7\nginx.exe

  ÉTAPE 7 — Vérifier
    pm2 list  →  formation-sav online (port 3001)
    http://localhost/NC/console.html  →  console admin NC
